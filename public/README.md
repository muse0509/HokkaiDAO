# public/

Drop the official **ctsDAO logo** here as `logo.svg` (preferred) or `logo.png`.

The site's `Logo` component (`components/Logo.tsx`) probes `/logo.svg` and swaps
it in automatically once present — no code change needed. Until then it renders a
clean Inter wordmark placeholder.

Brand rules for the mark:

- Place it on a solid **Washi White `#F4F1EA`** background only.
- Keep generous clear space around it.
- Do **not** recolor, stretch, rotate, or place it over images / busy backgrounds.
